# Référentiel de rédaction DevDoc

**Statut : premier jet du 26 octobre 2026, adapté du référentiel de Formation IA, à valider par le responsable éditorial.**
Tant qu'il n'est pas validé, il sert de base de travail ; une règle contestée se corrige ici avant d'être appliquée.

Ce référentiel dit ce qu'un cours ou un QCM de DevDoc doit respecter. Il est lu par les personnes qui rédigent et par les connecteurs MCP de rédaction ; les contrôles automatiques renvoient à ses identifiants.

## Lire une règle

Chaque règle a un identifiant stable (`RED-01`), un énoncé et son application dans un cours. Toutes sont des règles du projet : elles évoluent avec lui.

## Public

Développeuses et développeurs qui apprennent ou révisent Symfony, Vue et l'écosystème web, du niveau débutant au niveau confirmé. Le niveau du cours est porté par le parcours, le module ou le niveau du catalogue.
