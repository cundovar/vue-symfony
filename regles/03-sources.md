# Sources

## SRC-01 — Une documentation officielle de référence

**Règle.** Un cours indique sa page de référence dans la documentation officielle (symfony.com, vuejs.org, php.net, developer.mozilla.org…) dans le champ `sourceOfficielle`, et contient un lien vers ce site.

**Dans un cours.** Le lien figure dans le texte, par exemple dans une partie « Pour aller plus loin ».

## SRC-02 — Vérification datée

**Règle.** Le champ `verifieLe` indique la date à laquelle le contenu a été comparé à la documentation officielle. Un cours sur une fonctionnalité qui change souvent est revérifié à chaque version majeure.
