## Lire cette documentation

- **Par question** : la barre latérale suit les questions qu'on se pose, de « qu'est-ce que c'est ? » à « comment c'est déployé ? ».
- **Par fonctionnalité** : une page de fonctionnalité relie l'écran, la route Vue, l'appel API, le code Symfony, les données et les tests. Voir [QCM et progression](/fonctionnalites/qcm), la page modèle.
- **Niveau de preuve** : un badge indique si une information est <Status is="code" />, <Status is="local" />, <Status is="ci" />, <Status is="prod" /> ou <Status is="prevu" />.
- **Liens vers le code** : ils ouvrent le fichier sur GitHub.
- **Recherche** : <kbd>Ctrl</kbd> + <kbd>K</kbd>.
